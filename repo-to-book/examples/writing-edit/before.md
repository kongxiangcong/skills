# 缓存的强大机制

让我们深入探索缓存。缓存不仅仅是一个存储空间，更是性能飞跃的重要基石。总的来说，这一机制非常值得关注。

**版本与范围：** 本例为教学假设，不是项目实测。假设版本为 v1.2，仅讨论单线程，读者懂 Python。本例不附源码，不宣称复现。假设源码位置为 `cache/core.py`，依据 [S01]。

**命中：** `get(key)` 命中时返回已有值，不调用 `compute(key)`。**未命中：** 未命中时调用 `compute(key)`，并把结果存入缓存。这一机制意义重大。

**容量：** 缓存最多保存 128 项，插入后超出上限时按插入先后移除最早插入的一项。命中不会改变插入顺序，因此此规则不是按最近访问时间淘汰。**清空：** `clear()` 清空所有项；下一次请求同键会重新计算。

总而言之，我们已经探讨了缓存的多个方面。未做性能测量，不能给出加速比例；并发安全性未知。
