# 一页编辑试验的材料

本例为教学假设，不是项目实测。读者懂 Python，想理解一个有界缓存为什么会重新计算。

- F1：假设版本 v1.2；仅讨论单线程。
- F2：`get(key)` 命中时返回已有值，不调用 `compute(key)`。
- F3：未命中时调用 `compute(key)`，并把结果存入缓存。
- F4：缓存最多保存 128 项；插入后超出上限时按插入先后移除最早插入的一项。
- F5：命中不会改变插入顺序，因此此规则不是按最近访问时间淘汰。
- F6：`clear()` 清空所有项；下一次请求同键会重新计算。
- F7：未做性能测量，不能给出加速比例；并发安全性未知。
- F8：假设源码位置为 `cache/core.py`，依据来源 [S01]；本例不附源码，不宣称复现。

仅以上事实可用于改写；不得查外网或加项目经历。目标是解释原因，完整接口索引属于参考资料，不要求每节四种形式。
