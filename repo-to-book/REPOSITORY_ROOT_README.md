## Repo to Book

两个可独立安装的技能位于 `repo-to-book/skills/`。在 `repo-to-book` 目录运行 `python scripts/install.py` 安装；其他模型也可直接读取写作技能的说明和离线研究包。研究完成后由用户另行启动写作，默认 HTML，PDF 按需。
