# 图书配色讨论

## 目标与边界
保留用户认可的杏红主体、三级加粗浅框与不同字号；减少红色元素。用户最新要求：阅读纸面使用纯白 #ffffff，不用暖白。仅原型评审，尚未应用正式模板。

## 问题地图
当前解释颜色分工：柔和表面与清晰文字可以共存。后续确认配色，再回到模板集成与 PDF 验证。

## 减法记录
去掉表头、正文图框、提示块和标题文字的重复红色；暂不增加多套彩色主题。仅用少量蓝灰区分图中对象。

## 证据与假设
2026-10-28 阅读 W3C WCAG 2.2 SC 1.4.3 官方说明（https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html）：普通文字最低 4.5:1，大字 3:1。这是可读性下限，不是美感或护眼证明。
阅读 Radix Colors 官方色阶说明（https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale）：背景、边框、文字承担不同职责。适用 UI，迁移到图书属于设计推断；官方页面未固定版本。仓库 HEAD 查询为 dbdb85470547c7d34b9001f48fddb08ded335979，单独 CSS 路径请求 404，本轮未验证其实现，不宣称使用 Radix 原始色值。
原型配色为自选。色彩面积与重复使用造成红色过多是待用户确认的假设；竞争解释是框线密度。固定内容、字号和布局，仅改配色，作为单用户视觉比较。
对比度采用 WCAG 相对亮度公式 (L亮+0.05)/(L暗+0.05)，实际数值保存在 /workspace/design-prototypes/repo-to-write/contrast-v2.txt。不是用户阅读实验。

## 理解进展
用户满意杏红主体，认为红色元素过多；颜色角色的方案待确认。
