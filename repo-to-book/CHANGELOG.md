# Changelog

## 2.1.0 · 2026-10-27

- 源码归档改为显式发布文件清单，拒绝符号链接及不合法路径。
- 新增完整研究补包 refresh：保留原稿、对比快照、失效受影响复核、删除过期产物；双重切换失败保留恢复备份。
- 分开部分稿构建与完整交付检查；保留研究范围历史，要求覆盖映射、删并理由及核心缺口处理记录。
- 缩小触发范围，两个技能均显式调用；根指令精简为职责、导航与完成标准。
- 开工按计划核对能力，缺工具/缺证继续独立章节，分别报告构建和视觉验收。
- 增加真实 boltons 优先队列研究示例与模型行为验收记录；实际范围和未完成项见 docs/VALIDATION.md。

## 2.0.0 · 2026-10-27

- 将一体式流程拆成 repo-to-research 与 repo-to-book 两个独立技能。
- 阶段一默认真实子代理分工；主 agent 规划/综合，不再负责最终书稿。
- 出图在研究阶段完成：diagram-design 精确图解，内置 imagegen 概念位图，记录真实来源与限制。
- 引入普通目录交接：逐章 materials、实际 assets、公共来源、必要 evidence、轻量索引。
- 用户手动启动阶段二；写作技能禁用隐式触发，不依赖 Codex、研究技能、出图服务或模型 API。
- 出版默认改为 HTML；PDF/浏览器依赖独立可选；完整图文源目录保留。
- 添加素材检查、选择性导出、独立写作目录准备、双技能安装和隔离回归测试。
- 技术 SVG 在手机窄屏局部滚动，避免无限缩小文字。
- 保留旧版 Markdown 出版能力，不自动把旧资料认成已完成研究包。

## v2.2 · 2026-10-27

- 写作技能改名 repo-to-write，保留外层 repo-to-book 与研究技能。
- 合并读者需求、结构组织和克制编辑规则，补中文教学假设、来源版本与许可。
- 更新安装/打包/交接引用；检测旧写作技能冲突，不自动覆盖。
- v2.1 快照、哈希和案例原始验收记录保留为 historical。
